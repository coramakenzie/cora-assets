Accessibility

Last updated November 16, 2026

Bananas Hair wants everyone to be able to use this website and visit the studio comfortably.

This website

We aim to follow the Web Content Accessibility Guidelines (WCAG) 2.1, Level AA. This site is built to:

  • Work with screen readers, with text descriptions on photos.
  • Be usable with a keyboard.
  • Respect your device’s “reduce motion” setting by turning off animations.
  • Work on phones, tablets and computers, and allow text to be zoomed.

Some content, such as older photos or links to other websites like Instagram, may not be fully accessible. We are working to improve the site over time.

The studio

If you have a disability or need an accommodation for your appointment, please let Deanna know when you book. We will do our best to help. Service animals are always welcome.
